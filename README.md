# Projeto de QA – Pão de Açúcar
Projeto de QA com planejamento e execução de testes manuais em funcionalidades de um sistema de supermercado, incluindo cenários de teste, casos positivos e negativos e registro de resultados.
# Projeto de QA – Pão de Açúcar

## Sobre o projeto

Este projeto tem como objetivo demonstrar conhecimentos práticos em Quality Assurance (QA), por meio do planejamento e documentação de testes manuais em funcionalidades de um sistema de supermercado.

## Objetivos

- Desenvolver cenários de testes.
- Validar funcionalidades do sistema.
- Identificar possíveis falhas.
- Documentar resultados dos testes.
- Aplicar técnicas de testes positivos e negativos.

## Escopo dos testes

Os testes foram organizados em uma matriz contendo:

- ID do teste;
- Funcionalidade;
- Cenário de teste;
- Pré-condições;
- Passos para execução;
- Resultado esperado;
- Resultado obtido;
- Status.

## Tipo de teste

- Testes manuais;
- Testes funcionais;
- Testes positivos;
- Testes negativos.

## Ferramentas utilizadas

- Google Sheets / Excel;
- GitHub;
- Documentação de testes.

## Documentação

A matriz de testes completa está disponível na pasta `documentos`.

## Objetivo profissional

Este projeto faz parte do meu processo de aprendizado e desenvolvimento profissional na área de Quality Assurance (QA), com foco em testes de software e garantia da qualidade.
